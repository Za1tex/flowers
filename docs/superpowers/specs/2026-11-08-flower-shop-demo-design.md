# Демо-сайт цветочного магазина «Пудровый сад»: дизайн

Дата: 2026-11-08
Репозиторий: `za1tex/flowers`

## Зачем это нужно

Владелец репозитория продаёт сайты малому бизнесу. Он звонит цветочным магазинам, рассказывает про сайт и показывает его по ссылке. Нужен один универсальный демо-сайт, который:

- сразу производит впечатление за счёт анимации (motion), хотя фотографий в нём нет;
- после покупки быстро переделывается под конкретный магазин: название, телефон, адрес, тексты, цены, фото.

Под клиента сайт будет переделывать не владелец, а Claude по его просьбе. Поэтому всё, что зависит от клиента, должно лежать в одном месте и меняться без риска что-то сломать.

## Цели

1. Демо выглядит дорого и «живо» без фотографий: на месте фото стоят аккуратные рамки-арки.
2. Переделка под клиента — это правка одного файла с настройками и добавление фото в папку.
3. Сайт хорошо работает на телефоне: клиенты магазинов в основном заходят с телефона.
4. Заказ — звонок по телефону магазина.
5. У демо есть публичная ссылка (GitHub Pages), которую можно отправить магазину.

## Не цели

- Корзина, онлайн-оплата, личный кабинет.
- Форма заказа, отправка в WhatsApp или Telegram (выбран только звонок).
- Админ-панель и CMS. Правки вносит Claude.
- Серверная часть и база данных.
- Несколько языков.

## Анти-цели (провал, даже если всё работает)

- Сайт выглядит как дешёвый шаблон или «сделано ИИ».
- Анимация тормозит или дёргается на средних телефонах.
- На телефоне что-то вылезает за экран, наезжает или обрезается.
- Пустые рамки выглядят как сломанные картинки, а не как задуманный дизайн.
- В сайте клиента остаются выдуманные отзывы или демо-телефон.

## Решения владельца

- Стиль — вариант A, «Пудровый сад», из набросков (`https://claude.ai/artifact/UKBfoA1qTB6cPW3fRbzxJo`): нежно-розовый фон, тёмно-зелёный текст, розовый акцент, медленно падающие лепестки, рамки-арки под фото, которые слегка покачиваются.
- Фото нет. Вместо них рамки.
- Разделы (все семь, порядок такой):
  1. Первый экран.
  2. Каталог букетов: карточки с рамкой под фото, названием, ценой и кнопкой «Заказать».
  3. Поводы: день рождения, свадьба, просто так и т. п.
  4. О магазине.
  5. Как заказать и доставка.
  6. Отзывы.
  7. Контакты.
- Кнопка «Заказать» звонит на телефон магазина.
- Переделывать под клиентов будет Claude.
- Репозиторий `za1tex/flowers`, публикация через GitHub Pages.

## Решения Claude (владелец их не обсуждал, можно поменять)

- **Технологии.** Обычные HTML, CSS и JavaScript без сборщика, фреймворков и npm. Сайт открывается на любом хостинге, его легко копировать под нового клиента.
- **Где лежат данные клиента (изменено после проверки).** Тексты, контакты, букеты, поводы и отзывы пишутся прямо в `index.html`, без подстановки скриптом. Так ссылка, отправленная в WhatsApp, Telegram или VK, показывает правильное превью, поисковики видят текст, и страница работает без JavaScript. Каждый блок, который меняется под клиента, помечен комментарием `<!-- КЛИЕНТ: ... -->`. Цвета вынесены в CSS-переменные в начале `css/style.css`. JavaScript отвечает только за анимацию.
- **Фото.** Рамка-арка — это `<figure class="arch">`. Пустая рамка показывает заглушку. Если внутрь положить `<img src="img/...">`, картинка встаёт в арку с обрезкой по форме.
- **Картинка превью ссылки (`og:image`).** PNG 1200×630, снятый с первого экрана: лепестки, арки, название. Генерируется скриншотом и лежит в `img/og.png`.
- **Поводы.** Карточки без фильтрации каталога. Кнопка на карточке звонит в магазин.
- **Заглушка рамки.** Это не серый прямоугольник: тонкая обводка арки, светлая заливка, маленькая подпись вроде «фото букета» и рисунок цветка тонкой линией. Пустая рамка должна выглядеть как задуманный элемент дизайна.
- **Звонок.** Все кнопки «Заказать» ведут на `tel:` с номером из настроек. На кнопке и в шапке номер написан текстом, чтобы на компьютере его было видно. На телефоне внизу экрана закреплена кнопка «Позвонить».
- **Анимация:**
  - первый экран: падающие лепестки (5–8 штук на телефоне, до 12 на компьютере), рамки-арки плавно покачиваются, заголовок появляется при загрузке;
  - блоки ниже плавно поднимаются и проявляются при прокрутке. Без JavaScript контент виден сразу и не прячется;
  - карточки при наведении слегка приподнимаются, арка «дышит»;
  - анимируются только `transform` и `opacity`, чтобы не тормозило;
  - при системной настройке «уменьшить движение» анимация отключается.
- **Шрифты.** Cormorant Garamond (заголовки, курсив) и Manrope (текст), оба с кириллицей, через Google Fonts.
- **Демо-данные.** Название «Лепесток», телефон-заглушка `+7 (900) 000-00-00`, адрес «ул. Цветочная, 1», 6–8 букетов с примерными ценами в рублях, 4–6 поводов, 3 отзыва. Всё это помечено в `index.html` как демо, а в README есть чек-лист, что заменить у клиента (отзывы — только настоящие или удалить блок).
- **Светлая тема только.** Розовый фон — часть стиля, тёмную тему не делаем.
- **SEO-минимум.** `title`, `description`, Open Graph (заголовок и описание из настроек), `lang="ru"`, разметка `Florist` в JSON-LD с данными из настроек.
- **Структура файлов:**
  ```
  index.html
  css/style.css   — цвета в переменных в начале файла
  js/main.js      — только анимация
  img/            — og.png; фото клиента (в демо их нет)
  README.md       — как запустить и чек-лист переделки под клиента
  ```
- **Публикация.** GitHub Pages из ветки `main`, корень репозитория. Включить Pages в настройках репозитория владелец должен сам: у Claude в этой сессии нет инструмента для этого.

## Сайты клиентов (решение владельца)

- Репозиторий `flowers` остаётся демо и шаблоном. Его ссылка всегда показывает демо.
- Когда магазин покупает сайт, владелец создаёт для него пустой репозиторий. Claude копирует туда файлы демо и переделывает копию под клиента. Демо при этом не меняется.
- В README есть чек-лист переделки: какие блоки с пометкой `КЛИЕНТ` заменить, куда положить фото, как пересоздать `img/og.png`, как включить GitHub Pages и подключить домен клиента.

## Оставлено на усмотрение исполнителя

- Точные тексты демо-контента, названия и цены букетов.
- Точная вёрстка каждого раздела в рамках стиля A.
- Конкретная реализация лепестков (CSS или canvas), если соблюдены ограничения по производительности.
- Мелкие декоративные элементы: тонкие линии стеблей, разделители.

## Проверка готовности

- Сайт открывается локально и без ошибок в консоли.
- Скриншоты на ширине 390 px и 1440 px: ничего не вылезает за экран и не наезжает.
- Пустая арка показывает заглушку, арка с `<img>` — картинку по форме (проверить на одном тестовом файле).
- Все кнопки «Заказать» и «Позвонить» ведут на `tel:` с номером из настроек.
- Смена цветовых переменных в начале `css/style.css` меняет цвета на всей странице.
- Превью ссылки (Open Graph) содержит название, описание и картинку `img/og.png`.
