# Лепесток: демо-сайт цветочного магазина

Одностраничный сайт в стиле «Пудровый сад». Вместо фото стоят рамки-арки, есть падающие лепестки, плавное появление блоков при прокрутке, заказ звонком.

Демо: https://za1tex.github.io/flowers/

Все данные в демо выдуманы: название, телефон `+7 (900) 000-00-00`, адрес, цены, отзывы.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | весь текст и контакты. Места для правки помечены `<!-- КЛИЕНТ: ... -->` |
| `css/style.css` | стили. Цвета и шрифты в первом блоке файла |
| `js/main.js` | только анимация: лепестки, появление блоков, шапка |
| `img/og.png` | картинка превью ссылки в мессенджерах (1200×630) |
| `tools/make-og.js` | пересоздаёт `img/og.png` с первого экрана |
| `tests/check.js` | проверки в браузере |

## Как открыть

Откройте `index.html` в браузере, сборка не нужна.

Проверки (нужен Node.js и Playwright с Chromium):

```
node tests/check.js
```

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → выбрать ветку и папку `/ (root)` → Save. Через минуту-две сайт откроется по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

## Чек-лист: сайт для нового клиента

Демо в этом репозитории не меняем. Для каждого клиента делаем копию.

1. Создать пустой репозиторий для клиента и скопировать туда все файлы, кроме `docs/`.
2. В `index.html` пройти по всем пометкам `КЛИЕНТ`:
   - `<title>`, `description`, все `og:*` (в `og:url` и `og:image` указать новый адрес сайта);
   - JSON-LD: название, телефон, адрес, город, часы работы, адрес сайта;
   - название в шапке и подвале;
   - телефон: заменить **везде** `tel:+79000000000` и `+7 (900) 000-00-00` (поиском по файлу);
   - тексты первого экрана, «О нас» и цифры, шаги заказа и условия доставки;
   - букеты: названия, состав, цены;
   - поводы;
   - отзывы: только настоящие. Если их нет, удалить раздел `#reviews` и пункт «Отзывы» в меню;
   - адрес, часы работы, ссылки на соцсети (сейчас `#`).
3. Цвета при желании поменять в первом блоке `css/style.css`.
4. Фото положить в `img/`. Чтобы фото встало в арку, у `<figure class="arch">` добавить класс `has-photo` и заменить её содержимое на `<img src="img/имя.jpg" alt="Описание букета">`. Подойдут вертикальные фото примерно 3:4, они обрежутся по форме арки.
5. Пересоздать превью: `node tools/make-og.js`.
6. Запустить `node tests/check.js`. Тесты проверяют демо-номер `+79000000000`: в копии клиента поменять `PHONE_HREF` в начале файла и строку `telephone` в проверке `meta-tags`.
7. Включить GitHub Pages и при необходимости подключить домен клиента (Settings → Pages → Custom domain).
